# ECH Test Setup Project – Bi-Weekly Timeline

This project aims to set up and test Encrypted ClientHello (ECH) on a Lighttpd web server
to evaluate privacy and functionality. Below is the planned schedule of tasks and 
deliverables in two-week increments.

| Period         | Goals / Deliverables                                                                 | Notes                                                   |
|----------------|---------------------------------------------------------------------------------------|--------------------------------------------------------|
| **Oct 14–27**  | - Begin learning LaTeX basics<br>- Set up Ubuntu, build tools, Git                    | Focus on environment setup and version control         |
| **Oct 28–Nov 10** | - Study ECH protocol<br>- Test basic TLS setup and certificates<br>- Research/testing strategy<br>- Document initial setup in LaTeX | Start simple diagrams or notes                         |
| **Nov 11–24**  | - Enable ECH on Lighttpd<br>- Capture test results with `bssl` / `openssl`<br>- Upload results to GitHub | Achieve a working proof-of-concept                     |
| **Nov 25–Dec 8** | - Test ECH using Chrome, Firefox, etc.<br>- Introduce Playwright for automated headless testing<br>- Validate ECH behaviour in real browsers<br>- Update LaTeX documentation | Include screenshots and command outputs                |
| **Dec 9–22**   | - Basic performance measurements<br>- Expand Playwright tests (timing, errors)<br>- Begin structured LaTeX report | Prepare graphs/charts                                  |
| **Dec 23–Jan 5** | - Mid-project review and summary<br>- Update GitHub with configs and Playwright code<br>- Produce short progress PDF |                                                        |
| **Jan 6–19**   | - Refine ECH setup and tests<br>- Improve Playwright traces, logs, screenshots<br>- Fix server or test issues | Keep repo updated                                      |
| **Jan 20–Feb 2** | - Finalise ECH implementation on Lighttpd<br>- Automate recurring Playwright tests (CI-ready) | Begin organising final report                           |
| **Feb 3–16**   | - Run comprehensive ECH tests<br>- Compare `bssl client` vs Playwright behaviour<br>- Draft full LaTeX report | Include methodology + analysis                         |
| **Feb 17–Mar 1** | - Review and refine LaTeX report<br>- Add figures, tables, diagrams, browser traces | Ensure clarity and reproducibility                     |
| **Mar 2–15**   | - Supervisor feedback and revisions<br>- Finalise Playwright scripts and documentation | Clean up repo + report                                 |
| **Mar 16–29**  | - Prepare presentation/demo<br>- Test demo setup (Lighttpd + Playwright interaction) | Keep slides concise and reproducible                   |
| **Mar 30–Apr 12** | - Submit final report and project deliverables<br>- Stretch Goal: PR to Lighttpd<br>- Present project | Ensure repo + PDF finalised                            |
